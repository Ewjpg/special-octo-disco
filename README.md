# Макс Штирнер. Единственный и его собственность

Перевод Б. В. Гиммельфарба и М. Л. Гохшиллера (СПб., 1907).

На [Lib.ru/Классика](http://az.lib.ru/s/shtirner_m/text_1845_der_einzige_und_sein_eigenthum.shtml) этот текст
выложен сплошным полотном. Здесь из него собрана нормальная книга.

## Что читать

| Файл | Для чего |
|---|---|
| [`book/stirner-edinstvennyi.epub`](book/stirner-edinstvennyi.epub) | Электронная книга (EPUB 3). Подходит для телефона (Apple Books, Google Play Книги, ReadEra, FBReader), читалок PocketBook/Kobo/ONYX, а также Calibre на компьютере. Для Kindle отправьте файл через «Send to Kindle». |
| [`book/stirner-edinstvennyi.html`](book/stirner-edinstvennyi.html) | Та же книга одной веб-страницей: скачайте и откройте в браузере. Читать можно по страницам (на широком экране — разворотом) или лентой. Есть оглавление, закладки, сноски во всплывающем окне, размер шрифта и запоминание места, где вы остановились. В этом файле закладки хранятся в браузере. |

Как листать: касание правого или левого края страницы, свайп, стрелки ← → (а также PageUp/PageDown и пробел) или ползунок внизу. Номер страницы считается по всей книге и зависит от размера экрана и шрифта.

## Что сделано с текстом

- **Структура.** Две части, главы и разделы оформлены заголовками. Есть оглавление и обложка.
- **Сноски.** 72 примечания стояли в тексте в [квадратных скобках]: ссылки на Евангелие, переводы латинских фраз, пояснения редакции и переводчиков. Теперь это нумерованные сноски.
- **Типографика.** Двойной дефис `--` заменён тире, прямые кавычки — «ёлочками» (вложенные — „лапками“), `...` — многоточием. В сокращениях и инициалах стоят неразрывные пробелы.
- **Ошибки распознавания.** Исправлены только явные ошибки, полный список — в `FIXES` в [`tools/build.py`](tools/build.py). Это латинские буквы вместо русских (`g обычай` → «в обычай», `тe6e` → «тебе»), испорченные иностранные слова (`кtre suprкme` → «Être suprême», `fЭr` → «für») и опечатки вроде «пусть спасения» → «путь спасения». Больше в тексте ничего не менялось.
- В нескольких абзацах исходника кавычки не сходятся: цитата тянется через несколько абзацев или кавычка потеряна. Там кавычки расставлены по месту, без вложенности.

## Как пересобрать

```sh
python3 tools/build.py source/lib.ru-original.txt book book/cover.png   # EPUB + book/model.json
python3 tools/build_web.py book/model.json book/stirner-edinstvennyi.html  # веб-версия
```

Нужен только Python 3, внешних библиотек не требуется. Собранный EPUB проходит проверку
[EPUBCheck](https://github.com/w3c/epubcheck) без ошибок и предупреждений.

`source/lib.ru-original.txt` — исходный текст в том виде, в каком он сохранён со страницы Lib.ru.

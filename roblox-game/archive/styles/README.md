# Отключённые стили

Четыре стиля-примера (Комета, Мираж, Гравитон, Бастион) временно убраны из игры.
Код рабочий: чтобы вернуть стиль, перенеси его файл обратно в `src/shared/Styles/` и пересобери место.
Как только в папке стилей появится хотя бы один выбираемый стиль, в игре снова включатся меню стилей,
способности на Z/X/C и шкала Резонанса.
